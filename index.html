AI tunnel test

Checks that this web page can reach the model on your laptop through the tunnel and get a grade back. Nothing you type is saved; it is only sent to the address you enter below.

1. Connection

Warm up loads the model into memory first, so the first grade is not slowed by loading.

2. Grade a sample answer

Per-criterion: the model must quote the student's own words for each rubric line. If the quote is not really in the answer, that line gets 0, and the page (not the model) adds up the total. It needs rubric lines written like "- text (2 points)".
